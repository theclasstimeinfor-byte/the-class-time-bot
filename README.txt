===================================================================
THE CLASS TIME - WHATSAPP AI LEAD FOLLOW-UP SOFTWARE PACKAGE
===================================================================

Files included in this folder:
1. server.js          -> Main Node.js + Express backend server for Meta WhatsApp Cloud API
2. package.json       -> Required Node.js dependencies
3. env.example.txt    -> Environment variables template (Rename to .env when running locally)
4. public/index.html  -> Complete English Admin Dashboard, Flow Builder & Simulator

Quick Start (Local Computer):
1. Install Node.js (LTS) from https://nodejs.org/en/download
2. Open Command Prompt / Terminal inside this folder
3. Run: npm install
4. Run: npm start
5. Open http://localhost:3000 in your browser
